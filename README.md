# NEXUS

A personal operating system: remembers, understands, recommends, helps execute — and learns from feedback.

- **Stack:** React 19 + TypeScript + Tailwind CSS 4, installable PWA (Vite), Supabase (Postgres + Auth + RLS).
- **Status:** Phase 1 (Foundation). See [docs/STATUS.md](docs/STATUS.md) and [docs/ROADMAP.md](docs/ROADMAP.md).
- **Setup:** [docs/SETUP.md](docs/SETUP.md).

```powershell
npm install
npm run check   # typecheck + lint + tests (incl. database RLS tests, no server needed)
npm run dev
```

Project memory lives in `docs/` (Forge). Start with [docs/PROJECT.md](docs/PROJECT.md).
